# Frontend de Armonía

Aplicación React con Vite. La puesta en marcha, las variables de entorno, el despliegue en Vercel y las reglas del sistema están en el [README principal](../../README.md).

| Comando | Qué hace |
|---|---|
| `npm run dev` | Servidor de desarrollo en `http://localhost:3000` |
| `npm run build` | Build de producción en `build/` |
| `npm run preview` | Sirve el build para probarlo |
| `npm test` | Tests con Vitest |
| `npm run lint` | ESLint |
